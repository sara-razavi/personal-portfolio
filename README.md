# personal-portfolio

 Personal portfolio website built with plain HTML and CSS (no frameworks, no JavaScript yet).

I wanted to try something for the web, so I made a site to show who I am and what I've built so far.

## Pages

- `index.html` - home page with a short intro
- `about.html` - a bit about me and my skills
- `projects.html` - list of my Python projects
- `contact.html` - my email and a contact form

All pages share one stylesheet, `style.css`.

## How to run

There is nothing to install. Just download or clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/sara-razavi/personal-portfolio.git
```
